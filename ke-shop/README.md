# 🛒 Kalyani E-commerce Shop

A complete e-commerce web application for Kalyani Enterprises built with Flask, SQLAlchemy, and Bootstrap.

## ✨ Features

- 🛍️ Product catalog with variants (capacity + warranty options)
- 🛒 Shopping cart system
- 👤 User registration & authentication
- 💳 Cash on Delivery payment
- 📦 Order management
- 🔐 Admin panel for product management
- 📱 Responsive Bootstrap design
- 💾 SQLite database (easily migrate to MySQL/PostgreSQL)
